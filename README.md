## Tecnologias do site

O projeto utiliza React, TypeScript, Vite, Framer Motion e Lucide Icons. O design emprega a paleta `#050507`, grafite e tons de roxo, glassmorphism, gradientes sutis, animações com suporte a `prefers-reduced-motion`, navegação responsiva e SEO básico.

## Estrutura

```text
src/
├── components/      # Elementos compartilhados e navegação
├── data/            # Experiências, tecnologias, projetos e redes sociais
├── sections/        # Seções independentes da página
├── App.tsx          # Composição da página e efeitos globais
└── styles.css       # Estilos e responsividade
```

## Executar localmente

```powershell
npm install
npm run dev
```

Para criar a versão de produção:

```powershell
npm run build
```

## Formatação

O projeto possui configuração em `.prettierrc.json`. Após instalar o Prettier, execute `npm run format` para formatar os arquivos.
